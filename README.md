# Toxic-MD — بوت واتساب بالعربية

بوت واتساب حديث مبني على Node.js وBaileys Multi-Device، مخصص لإدارة المجموعات والحماية والأتمتة والذكاء الاصطناعي والتنزيل والتحرير والألعاب.

## المزايا

- إدارة المجموعات والحماية من الروابط والكلمات المسيئة والرسائل المزعجة.
- أوامر للذكاء الاصطناعي والبحث والتنزيل وتحرير الوسائط.
- دعم الأجهزة المتعددة وإعدادات قابلة للتخصيص وتقارير تلقائية.
- جميع الرسائل والواجهات باللغة العربية الفصحى.

## التشغيل

```bash
npm install
npm start
```

اضبط متغيرات البيئة المطلوبة، ومنها `SESSION`، قبل التشغيل. أسماء الأوامر والاختصارات التقنية تبقى بالإنجليزية لتعمل دون تغيير.
